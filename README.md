# FORGE — independent athletic storefront

Een originele, statische sport-fashion storefront met een editorial e-commerce uitstraling.

## Bewuste ontwerpkeuzes
Dit concept is **niet** gebouwd als pixel-voor-pixel kopie van Nike.com. Het gebruikt een eigen merknaam, eigen typografie, eigen kleurenpalet, eigen abstracte visuals, eigen productnamen en eigen copy. De inspiratie zit op hoog niveau in de conventies van moderne sportretail: hero, categorieën, productkaarten, editorial content en een winkelmand.

> Dit is geen juridisch advies en geen garantie dat een website nooit tot een geschil kan leiden. Laat een jurist het uiteindelijke merk, logo, teksten, afbeeldingen en handelsimago controleren voordat je commercieel lanceert.
